# Contributing to ROBOTIKO v2.0
> **Status:** Skeleton — Full version coming at EP10 open source release.

Thank you for your interest in ROBOTIKO v2.0. This project is currently in active production. Full contribution guidelines will be published when the project goes open source after EP10 completion.

---

## Before Contributing

1. **Read the Master** — `_management/master.md` is the absolute source of truth. Every contribution must honor its rules.
2. **Read the Pipeline** — `_management/pipeline_rules.md` defines the workflow. No steps can be skipped.
3. **Read the Naming Convention** — `_management/naming_convention.md` defines all file naming rules. Violations will be rejected.

---

## What You Can Contribute

- **Skill improvements** — Better SKILL.md definitions for existing skills
- **New skills** — Additional workflow automations
- **Bug fixes** — Pipeline errors, naming violations
- **Documentation** — Improvements to `docs/`
- **Test coverage** — Additional test scripts under `tests/`

---

## What You Cannot Change

- `_management/master.md` — The Universe Bible is locked. Open an issue to discuss changes.
- `_assets/cast/character_profiles.json` — Character design decisions are final for the current season.
- The mandatory visual suffix — It must appear on every visual prompt without exception.

---

## Process

1. Fork the repository
2. Create a branch: `git checkout -b feature/your-feature-name`
3. Make your changes
4. Run tests: `python tests/naming_check.py`
5. Submit a Pull Request using the PR template

---

## Code of Conduct

This project embodies the symbiosis philosophy of ROBOTIKO v2.0 — human and AI working together with respect and intention. Contributions should reflect this spirit.

*"Even if you are hurt, do not hurt others."*
