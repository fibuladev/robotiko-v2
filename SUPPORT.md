# Support

This is a solo-maintained project. Here's where things go.

## Questions about using the method

Have a question about forking the pipeline, running a skill, or setting up
the toolchain? Start with:

- [docs/getting-started.md](docs/getting-started.md) — prerequisites, clone-to-first-episode walkthrough, FAQ
- [docs/tools-setup.md](docs/tools-setup.md) — per-tool setup (Claude Code, Suno, Nano Banana, Kling/Veo/Seedance, CapCut, MCP)
- [CONTRIBUTING.md](CONTRIBUTING.md) — the full "fork the method" path

Still stuck? Ask in
**[GitHub Discussions](https://github.com/fibuladev/robotiko-v2/discussions)**
(Q&A category) once Discussions is enabled on the repo. It's the right place
for "how do I..." questions that aren't a bug in this repo's code.

## Bugs

Found something actually broken in the pipeline, a script, a validator, or a
skill? Open an issue with a reproduction — see the
[bug report template](.github/ISSUE_TEMPLATE/bug_report.md). Vague reports
without a repro step are hard to act on; a specific file, command, or
episode makes it real.

## Feature ideas

Have an idea for a new skill, script, or validator? Use the
[feature request template](.github/ISSUE_TEMPLATE/feature_request.md).

## "I forked this and built my own universe"

That's the main use case — see it celebrated, not just tolerated, at
[UNIVERSES.md](UNIVERSES.md). Register it with the
[universe showcase template](.github/ISSUE_TEMPLATE/universe_showcase.md).

## Questions about the ROBOTIKO story itself

Canon questions (not canon changes — see
[GOVERNANCE.md](GOVERNANCE.md)) go through the
[canon question template](.github/ISSUE_TEMPLATE/canon_question.md).

## Security

Do not use any of the above for a credential or vulnerability report — see
[SECURITY.md](SECURITY.md) instead.

## Response time

One maintainer, working on this in personal time around a full-time day
job. Best-effort, not instant. See [GOVERNANCE.md](GOVERNANCE.md) for the
honest version of that tradeoff.
