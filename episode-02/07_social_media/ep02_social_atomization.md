### One-Time Template Setup (CapCut Desktop)

Do this once. All 4 clips reuse the same template.

1. **New project:** CapCut Desktop → New Project → canvas size **9:16 (1080×1920)**
2. **Background:** Click the canvas background → set color to pure black (#000000)
3. **Import any clip:** Drag any EP02 clip onto the timeline (placeholder — you'll swap it later)
4. **Resize video:** Select the clip on the canvas → lower the **Scale** until the full 16:9 frame fits inside the 9:16 canvas with black bars above and below (~60% scale). The video must NOT fill the screen — the bars are the point
5. **Center it:** Drag the video so the black bars above and below are roughly equal
6. **Top bar text:** Click **Text → Add Text** → type `ROBOTIKO v2.0` → set font to the closest available serif in CapCut (search "serif" or "classic" — exact font varies by version) → color: **#D4A76A** (warm amber/gold) → size: ~36pt → drag to the **upper-left** of the top black bar → stretch the text element's duration to match the full clip
7. **Bottom bar text:** **Text → Add Text** → type `8 → ∞` → same font, same color → drag to the **lower-right** of the bottom black bar → same duration as clip. CapCut's kerning and alignment are limited — manual positioning is fine. Slight imperfection fits the analog aesthetic.
8. **Film grain (optional):** Go to **Effects** → search "film grain" or "noise" → drag onto the timeline above the video → lower opacity to 10-15% → this adds analog texture to the black bars
9. **Save as template:** File → Save Project As → name it "ROBOTIKO_Cinematic_Canvas_Template"

### Per-Clip Workflow

For each of the 4 clips, repeat:

1. **Duplicate** the template project (File → Save Project As → new name, e.g., "EP02_Clip1_Guru")
2. **Replace video:** Delete the placeholder clip on timeline → drag in EP02 final video
3. **Trim:** Place the playhead at the start timestamp → Split (Ctrl+B) → place playhead at end timestamp → Split → delete everything outside the target range
4. **Adjust text duration:** Select each text element → drag its edges to match the trimmed clip's length
5. **Preview:** Play it back — check that video is centered, text is visible, no elements are cut off
6. **Export:** Export → Resolution: 1080×1920 → Frame rate: 30fps → format: MP4
